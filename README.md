# 挖坑备忘录

一个基于 PySide6 的桌面备忘录工具，包含任务流转（挖坑系统）和时间排序备忘录。

## 功能

### 坑系统
- 三栏流转：**挖坑**（待开始）→ **填坑**（进行中）→ **完结坑**（已完成）
- 支持按钮流转（↑↓）和拖拽流转
- 完结坑支持一键「重新挖坑」
- 完整增删改查

### 备忘录
- 按创建时间排序，支持拖拽排序
- 勾选完成功能（勾选后透明度 +15%）
- 完整增删改查

### 主题与设置
- 白天 / 黑夜 / 自定义三模式切换
- 自定义颜色：背景色、文字色、边框色（Hex 颜色代码）
- 透明度滑块、字体大小、开机自启
- 窗口位置和大小自动记忆

### 桌面增强
- 桌面固定：置顶 + 半透明悬挂，固定时只读
- 最小化到系统托盘，双击托盘图标恢复

### 窗口
- 无系统标题栏，自定义标题栏
- 窗口圆角边框
- 边缘拖拽缩放

## 数据存储

三个 JSON 文件（自动生成在 exe 同级目录）：

| 文件 | 用途 |
|------|------|
| `Hole.txt` | 坑数据 |
| `list.txt` | 备忘录数据 |
| `data.txt` | 设置数据 |

## 环境要求

- Python 3.8+
- PySide6 >= 6.5.0

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

## 打包为 EXE

```bash
pip install pyinstaller
build.bat
```

打包后 exe 位于 `dist\挖坑备忘录.exe`，可放到任意目录运行。

## 项目结构

```
HoleList/
├── main.py              # 主窗口、托盘、主题、桌面固定
├── data_manager.py       # 数据持久化（JSON 读写）
├── hole_page.py          # 坑页面（三栏、流转、增删改查）
├── memo_page.py          # 备忘录页面（排序、勾选、拖拽）
├── settings_dialog.py    # 设置对话框
├── build.bat             # PyInstaller 打包脚本
└── requirements.txt      # 依赖
```
